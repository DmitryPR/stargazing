type: concept
title: Sky target
status: approved
updated: 2026-11-07
---

A sky target is one catalog name Stellarium can select, such as `Moon`, `Mars`, or `Saturn`.

A person's search string becomes a sky target only when the Remote Control connector returns that exact catalog name. Extra names that merely contain the string, such as `Mars I` when the person asked for `Mars`, are not the target.

The accepted catalog name is the only string passed to focus.
